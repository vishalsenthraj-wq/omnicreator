Privacy Policy — OmniCreator AI

Last updated: August 15, 2026

OmniCreator AI ("the app") is a comment-triage tool for a single connected Instagram Business Account. This policy explains what data the app accesses, how it is used, and how it is stored.

What data we access

Using the Instagram Graph API and the permissions granted by the connected account's owner, the app reads:

  • Recent posts (media) on the connected Instagram Business Account
  • Public comments left on those posts, including the commenter's username and comment text

The app does not access Instagram direct messages, does not access any account other than the one explicitly connected by its owner, and does not access data belonging to Instagram users beyond what is necessary to display and reply to their public comments.

How the data is used

  • Each new comment is classified into one of four categories (fan praise, business collaboration inquiry, resource request, or spam) using Google's Gemini AI, with the comment text sent to Gemini's API for that purpose.
  • For non-spam comments, a suggested reply is drafted, either by Gemini AI or by a built-in template, personalized with the commenter's username.
  • Comments identified as potential business/sponsorship inquiries trigger a push notification to the account owner's phone via ntfy.sh, so real opportunities are not missed.

Human approval before any public action

The app never posts anything to Instagram automatically. Every suggested reply is held in a "pending approval" state and displayed to the account owner in a private dashboard. A reply is only posted back to Instagram, via the Instagram Graph API, after the account owner explicitly clicks "Approve" — and they may edit the reply text first, or reject it instead so nothing is posted.

Data storage

Comment data, classification results, and reply status are stored locally in a SQLite database on the machine running the app. This data is not sold, shared with advertisers, or used for any purpose beyond operating the comment-triage workflow described above.

Third-party services used

  • Instagram Graph API (Meta) — to read comments and post approved replies
  • Google Gemini API — to classify comments and draft suggested replies
  • ntfy.sh — to deliver push notifications for business-collaboration leads

Each of these services processes the minimum data necessary to perform its function (e.g., comment text sent to Gemini for classification). Refer to each provider's own privacy policy for how they handle data sent to their APIs.

Data retention and deletion

Data is retained locally for as long as the account owner runs the app. The account owner may delete all stored data at any time by deleting the local database file.
